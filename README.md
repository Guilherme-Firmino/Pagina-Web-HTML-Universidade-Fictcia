# Pagina-Web---HTML---Universidade-Fictcia

A proposta foi simular o site oficial de uma universidade, apresentando informações institucionais, área de contato e seção “Sobre Nós”, utilizando boas práticas de organização e estrutura de conteúdo.

- Objetivo do Projeto

O principal objetivo deste projeto é:

Demonstrar domínio da linguagem HTML

Aplicar estruturação adequada de conteúdo

Organizar informações institucionais de forma clara

Simular um ambiente real de site universitário

Criar uma base sólida para futuras implementações com CSS e JavaScript

- Sobre a Página

A página apresenta o site institucional de uma universidade fictícia, contendo:

Página inicial com identidade visual baseada em imagens

Seção quem somos, com informações institucionais

Área de Contato

Organização visual estruturada por blocos de conteúdo

Uso de imagens para compor a identidade do projeto

O projeto foi desenvolvido com foco na clareza estrutural e na organização do conteúdo.

- Tecnologias Utilizadas
